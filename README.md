# Opulence Money - Personal Finance Tracker

Opulence Money is a comprehensive web application designed to empower users to manage their finances effectively. It features tools for tracking income and expenses, analyzing budget adherence, calculating net worth, and receiving AI-driven financial insights.

This project was developed as part of the **DurHack Hackathon**

**View the Live Demo:** [https://striker104.github.io/opulencemoney/Landing%20page/home.html](https://striker104.github.io/opulencemoney/Landing%20page/home.html)

---

## Core Features

* **Dashboard Overview:** Provides a quick summary of current net worth, budget status, and recent income/expense trends.
* **Income & Expense Tracker:** Simple forms allow users to log income and outgoing transactions, categorizing them for better analysis.
* **Budget Management:** Users can set budgets for different categories and visually track their progress with charts (e.g., pie charts).
* **Net Worth Calculation:** Tracks assets and liabilities over time.
* **AI Financial Assistant (OpulenceAI):** Integrates generative AI (accessible via a prompt interface) to provide personalized budgeting advice and financial feedback based on user data.
* **Responsive UI:** Built with Bootstrap, the interface is designed to be user-friendly and functional across different screen sizes.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap.
* **AI Integration:** Utilized generative AI (implementation likely via API) with prompt engineering to deliver personalized insights.
* **Hosting:** Deployed as a static site using GitHub Pages.
